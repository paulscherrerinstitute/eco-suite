# Turn your desktop layout into a one-click dashboard

eco desktop saves its dock layout and open widgets when it closes
(**Workspace → Reload Last Workspace** brings them back).
**Workspace → Save Startup Script...** writes a single `.sh` that starts a
desktop with just those widgets, everything else left uninitialized: a fast
dashboard to share or put on a control-room screen.
**Tools → Combine Panels into Tabs...** stacks panels as tabs.
