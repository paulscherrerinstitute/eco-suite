# Every command you typed is on a searchable timeline

All eco consoles log their input and output. Browse every session on one
zoomable timeline, filter it, and turn selected entries back into a script
with **Copy Selected as Script**:

```python
eco.logs.widget()        # also: desktop menu Tools -> Log Viewer
eco.logs.tail(20)
```
