# %ei knows what was written in SciLog

`%ei` searches Bernina's SciLog logbooks along with the command history
and the docs, indexed locally before the first question (~20 s once, then
less than a second). With a personal token it reads every logbook your PSI
groups can read; without one, and always on gac-bernina, it reads as the
beamline account. Either way it reads only what that account can read *now*.

```python
%ei --scilog-token                      # who reads SciLog here
%ei what trigger settings did we use for the tapedrive?
```
