# The docs and these tips are one call away

`features()` shows these tips in a small window; **Back** / **Next** walk
through them.
`docs()` opens the documentation in the browser, or one page of it. Without a
display, both print instead.

```python
docs("scanning")          # docs() for the start page
features("task-queues")   # the tip whose file name contains "task-queues"
```
