# Sometimes a chicken keeps you company while %ei thinks

While the model is working on an answer, the terminal shows a spinner
with the seconds waited. About one question in four gets a small animation
instead, chosen at random, and there are five. Which ones? Ask a few
questions and see.

```python
%ei which came first, the chicken or the egg?
```

`"wait_animations"` in `~/.eco/ei.json` sets how often (0 for never).
