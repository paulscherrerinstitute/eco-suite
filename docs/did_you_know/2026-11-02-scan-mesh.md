# Every scan records the point each step measured

The scan info now holds the scan's mesh, `scan_parameters["mesh_specs"]`:
dimension names, units, kind and the points measured. Each step's
`mesh_index` gives the point it measured, so a point measured twice is found
by index, without comparing floats. This also covers adaptive scans and
co-moving axes, which have no regular grid.

```python
scan.scan_info["scan_parameters"]["mesh_specs"]["kind"]   # "grid", "adapted", "line" or "path"
```
