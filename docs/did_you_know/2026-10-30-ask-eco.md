# Ask eco how to do something

`%ei` answers questions about using eco from the command history, the docs
and eco's API, with the devices of your session. Its code is never run for
you: `%ei --paste` puts it at the prompt. In eco desktop: **Ask** menu.

```python
%ei how do I do a mesh scan with two co-moving motors?
%ei and how do I queue that?      # follow-up
```
