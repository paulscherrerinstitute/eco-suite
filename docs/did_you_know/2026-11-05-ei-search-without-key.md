# `%ei` works without a model key: as a search

Without a key, `%ei` lists the best matches in the docs, eco's source, the
command history and the logbooks, each with where it is. Before its first,
longer indexing it shows the search syntax and asks whether to index now.

```python
%ei attenuator transmission
%ei --open 2
```
