# Keep a second reflection in Bragg while you move in hkl

`recspace` (on `xrd`, `gps`, `rob` and in the namespace) is the
hklforge-based successor of the `diffcalc` objects, with the same interface.
It returns every solution exactly, can keep a second reflection in Bragg
condition while `hkl` moves, and shows a clickable 3D view of each solution.
It runs alongside `diffcalc` with its own files, so trying it changes
nothing there.

```python
rs = xrd.recspace
rs.constraints.chi(None)
rs.constraints.h2([2, 2, 0])          # keep (220) in Bragg too
rs.si.hkl.mv([1, 1, 1])               # (111) and (220) both in Bragg
```

`rs.set_constraints()` lists the stored Bernina setups.
