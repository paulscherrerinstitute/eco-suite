# Read a SciLog logbook as one flow, with an outline

`scilog.viewer()` shows a logbook day by day, "Today", "Yesterday",
"Friday", with an outline to jump to any post or heading. Its search
tolerates typos and shows each match in its context. Plots attached as HTML
run inline.

```python
scilog.viewer()
```
