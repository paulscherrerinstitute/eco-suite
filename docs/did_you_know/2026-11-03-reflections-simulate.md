# Which reflection would I hit at these angles?

In the reflections browser, **simulate angles** takes any six circle
angles, typed, taken from the view or the current ones. It shows the hkl in
the Bragg condition there, the nearest integer reflection, the virtual
angles and the limit check, and draws the position in the 3D view. Nothing
moves.

```python
si.widget_reflections(1, 1, 1)
```
