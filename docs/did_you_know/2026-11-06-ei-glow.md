# `%ei` answers look nicer with glow

Where [glow](https://github.com/charmbracelet/glow) is installed, as on the
consoles, a finished `%ei` answer is rendered: headings, lists and
highlighted code instead of `**` and backticks. `"render": "plain"` in
`~/.eco/ei.json` switches it off.
