# eco on your phone

`eco web` serves the running session to a browser, made for phones and
tablets: the namespace, live values, moves, tweak and jog, pinned strip
charts, schematic panels, task queues and the cameras. It is the same session
as the terminal, read-only unless started with writes, and reached through
an SSH tunnel.

```python
eco.start_web()                 # from a running session; prints the link
eco.start_web(writes=True)      # moves allowed from the browser
```
