# LED, gauge and dial gadgets for a LabVIEW-style live panel

Small one-per-value indicator widgets (LED, bar gauge, slider, enum buttons,
large number tile, ...) with the same function names in Qt and in ipywidgets,
so a panel can move between the desktop and a notebook unchanged.
