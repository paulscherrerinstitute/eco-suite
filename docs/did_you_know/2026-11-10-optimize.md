# Align several coupled axes in one go

`scans.optimize` maximises a live signal over several axes at once: it finds
which combinations of axes matter, lets a delay follow the path-length
changes (calibrated on the way), checks whether a better maximum could hide
elsewhere, and ends at the best point. Every point is an ordinary, recorded
scan step. Try it on the simulated THz focus:

```python
t = sim.thz_focus
scans.optimize([t.par_x, 0.03], [t.mir_rz, 0.05], [t.delay, 0.08], exposure_def=0.2,
               feedback=t.signal, follow={t.delay: "calibrate"})
```
