# `%ei` checks its code against eco before you run it

An old logbook post can suggest a method that no longer exists. `%ei` reads
the code of each answer against eco's source and your session: attributes,
keywords and imports. If something doesn't fit, the model corrects it, and
anything left over is marked **Not verified**.
